# WhispBot

Telegram-бот для транскрибации аудио и видео в текст через OpenAI-совместимый Whisper API.

Поддерживает модели `whisper-large-v3`, `whisper-large-v3-turbo`, `whisper-1` и любые другие через смену параметра.

## Требования

- Python ≥ 3.10
- [uv](https://docs.astral.sh/uv/) (менеджер пакетов)
- [ffmpeg](https://ffmpeg.org/) (конвертация аудио)

## Установка

```bash
git clone <repo>
cd whispbot
uv sync
```

## Настройка

Скопировать `.env.example` в `.env` и заполнить:

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | — |
| `WHISPER_API_BASE_URL` | Адрес Whisper API | — |
| `WHISPER_API_KEY` | API-ключ | — |
| `WHISPER_MODEL` | Модель при старте | — |
| `WHISPER_PROMPT` | Опциональный системный промпт | `""` |
| `FILES_MAX_FILE_SIZE_MB` | Максимальный размер файла (MB) | `25` |
| `FILES_TEMP_DIR_PATH` | Путь к временной папке | `"temp"` |
| `FILES_ALLOWED_AUDIO_EXTENSIONS` | Разрешённые аудиоформаты | `".mp3,.wav,.m4a,.flac,.aac,.opus,.ogg,.wma,.aiff"` |
| `FILES_ALLOWED_VIDEO_EXTENSIONS` | Разрешённые видеоформаты | `".mp4,.webm,.mkv,.mov,.avi,.flv,.m4v,.3gp,.ts"` |
| `FILES_KEEP_TEMP_FILES` | Не удалять файлы после обработки | `"false"` |
| `ACCESS_ALLOWED_USERS_FILE` | Файл списка разрешённых пользователей (первая строка — администратор) | `"allowed_users.txt"` |
| `ACCESS_IGNORED_USERS_FILE` | Файл списка игнорируемых пользователей | `"ignored_users.txt"` |
| `LOG_LEVEL` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`) | `"INFO"` |

## Запуск

Вы можете запустить бота несколькими способами:

- Обычный запуск (если окружение уже настроено):
  ```bash
  .venv\Scripts\activate
  python -m src.bot
  ```
- Через скрипт с занятием консоли (удобно для отладки):
  - Windows PowerShell: `.\scripts\start-cli.ps1`
  - Ubuntu/Bash: `./scripts/start-cli.sh`
- **Холодный старт** (автоматически проверяет/устанавливает зависимости, затем запускает бота в переднем плане):
  - Windows PowerShell: `.\scripts\start-cold.ps1`
  - Ubuntu/Bash: `./scripts/start-cold.sh`

Остановка: `Ctrl+C` (для запущенного в переднем плане) или используйте скрипты управления (см. ниже).

## Управление

Набор скриптов в папке `scripts/` управляет ботом. Есть версии для Windows PowerShell и Ubuntu/Bash.

### Windows 11 / PowerShell

Если PowerShell блокирует выполнение («running scripts is disabled on this system»), один раз выполните
`scripts\fix-bot.ps1` — он включит политику выполнения `RemoteSigned` для текущего пользователя (без прав администратора, повторный запуск безопасен):

| Скрипт | Назначение |
|---|---|
| `scripts\fix-bot.ps1` | Однократное исправление политики выполнения PowerShell (`RemoteSigned`, только текущий пользователь) |
| `scripts\start-bot.ps1` | Запуск бота в фоне (скрытое окно, PID → `run/bot.pid`) |
| `scripts\start-cli.ps1` | Запуск бота на переднем плане — консоль занята до остановки (Ctrl+C), стиль и проверки те же, что у остальных скриптов |
| `scripts\status-bot.ps1` | Статус: запущен/не работает, время работы, сколько уникальных пользователей написали и сколько сообщений обработано с момента запуска |
| `scripts\restart-bot.ps1` | Остановка и повторный запуск (в фоне) |
| `scripts\stop-bot.ps1` | Остановка бота |
| `scripts\start-cold.ps1` | **Холодный старт** — проверяет/устанавливает зависимости, затем запускает бота в переднем плане |

Примеры:

```powershell
.\scripts\fix-bot.ps1
.\scripts\start-bot.ps1
.\scripts\start-cli.ps1
.\scripts\status-bot.ps1
.\scripts\restart-bot.ps1
.\scripts\stop-bot.ps1
.\scripts\start-cold.ps1
```

### Ubuntu 24.04 / Bash

Сделайте скрипты исполняемыми один раз: `chmod +x scripts/*.sh`
Если нужно исправить права или проверить зависимости, выполните `scripts/fix-bot.sh`:

| Скрипт | Назначение |
|---|---|
| `scripts/fix-bot.sh` | Проверяет права доступа и зависимости (ffmpeg, uv, .env) |
| `scripts/start-bot.sh` | Запуск бота в фоне (PID → `run/bot.pid`) |
| `scripts/start-cli.sh` | Запуск бота на переднем плане — консоль занята до остановки (Ctrl+C) |
| `scripts/status-bot.sh` | Статус: запущен/не работает, время работы, количество уникальных пользователей и обработанных сообщений |
| `scripts/restart-bot.sh` | Остановка и повторный запуск (в фоне) |
| `scripts/stop-bot.sh` | Остановка бота |
| `scripts/start-cold.sh` | **Холодный старт** — проверяет/устанавливает зависимости (в том числе делает скрипты исполняемыми), затем запускает бота в переднем плане |

#### Как управлять ботом

Все скрипты используют общий модуль `scripts/whispbot-env.sh`, в котором определены пути, проверка процесса по PID-файлу и функции запуска/остановки. Это означает, что бот управляется одинаково независимо от того, как он был запущен (в фоне, в переднем плане или через systemd).

**Особенности:**
- **Однократная проверка экземпляра** — `start-bot.sh` и `start-cli.sh` проверяют, не запущен ли уже бот, и отказываются стартовать второй.
- **Корректная остановка** — `stop-bot.sh` ждёт graceful exit до 15 секунд, затем принудительно завершает SIGKILL. PID-файл удаляется только если он всё ещё указывает на остановленный процесс (защита от гонки при одновременном старте/остановке).
- **Чтение статистики** — `status-bot.sh` использует `jq`, если он установлен, иначе падает на встроенный Python. Не требует дополнительных зависимостей.
- **Холодный старт** — `start-cold.sh` устанавливает `uv` через официальный инсталлятор, запускает `uv sync`, проверяет Python ≥ 3.10 и ffmpeg, затем стартует бота в переднем плане.

Примеры:

```bash
./scripts/fix-bot.sh
./scripts/start-bot.sh
./scripts/start-cli.sh
./scripts/status-bot.sh
./scripts/restart-bot.sh
./scripts/stop-bot.sh
./scripts/start-cold.sh
```

Все способы запуска (`start-bot.*`, `start-cli.*`, прямая команда `python -m src.bot`) используют общий механизм: бот при старте регистрирует свой PID в `run/bot.pid` и ведёт `run/stats.json`, поэтому остальные скрипты видят и управляют любым экземпляром. Перед запуском скрипты проверяют, не работает ли уже другой экземпляр, и отказываются стартовать второй.

Рабочие файлы лежат в `run/` (папка в `.gitignore`): `bot.pid`, `bot.out.log`, `bot.err.log`, `stats.json`. Счётчики «пользователей» и «сообщений» собирает сам бот (`src/stats.py`) и обнуляются при каждом запуске — после рестарта отчёт показывает только текущий процесс.

## Команды

| Команда | Описание |
|---|---|
| `/start` | Обычный режим (двухфазный: «Слушаю...» → текст) и показ ваших текущих настроек |
| `/startmin` | Минимальный режим (одно сообщение с результатом, без «Слушаю...») |
| `/help` | Справка по всем командам и форматам |
| `/lang <код>` | Установить язык распознавания (ISO-639-1: `ru`, `en`…) или `auto` |
| `/temp <0.0–1.0>` | Установить температуру модели (разделитель `,` или `.`) |
| `/model large` | Переключиться на `whisper-large-v3` |
| `/model turbo` | Переключиться на `whisper-large-v3-turbo` |
| `/adduser <id> [имя]` | Добавить пользователя в список разрешённых и удалить из игнорируемых (только для администратора) |
| `/deluser <id>` | Переместить пользователя из разрешённых в игнорируемые (только для администратора) |
| `/listuser` | Показать двумя сообщениями списки разрешённых и игнорируемых (только для администратора) |

## Уведомления при старте

При запуске бот отправляет администратору (первому пользователю в `allowed_users.txt`) отдельное сообщение:

> 🎙️ *WhispBot запущен и готов к работе!*
>
> Бот успешно стартовал и слушает входящие сообщения. Отправьте аудио или видео — и получите расшифровку.

Уведомление отправляется через `post_init` — то есть после того, как соединение с Telegram установлено и polling начался. Если администратор не задан (список разрешённых пуст), уведомление пропускается с предупреждением в логе. Ошибка при отправке не останавливает бота.

## Использование

Отправьте боту аудио (MP3, WAV, M4A), видео (MP4, WEBM), голосовое сообщение или кружок — бот вернёт текстовую расшифровку.

По умолчанию включён **двухфазный режим**: сначала «Слушаю...», затем замена на текст. Команда `/startmin` переключает в **минимальный режим** — бот сразу отвечает одним сообщением с результатом (полезно для цепочек ботов).

## Индивидуальные настройки

Настройки транскрибации (**язык**, **температура**, **модель**, **режим ответа**) индивидуальны для каждого пользователя и хранятся в памяти бота (`context.user_data`), поэтому сбрасываются при его перезапуске.

- Команда `/start` показывает текущее состояние ваших настроек.
- Команды `/lang`, `/temp`, `/model`, `/startmin` меняют настройки только для вызвавшего их пользователя и не влияют на остальных.

Поддерживаемые типы входящих сообщений:
- **Аудиофайлы** — конвертируются в WAV (16kHz, mono) через ffmpeg
- **Видеофайлы** — извлекается аудиодорожка, затем транскрибация
- **Голосовые сообщения** (Voice) — конвертация OGG → WAV
- **Видеокружки** (Video Note) — извлечение аудио из MP4
- **Документы** — если расширение в списке разрешённых

## Доступ пользователей

Бот читает два списка при старте (формат строки: `<user_id>; <имя или комментарий>`, строки с `#` и пустые пропускаются):

- **`allowed_users.txt`** — разрешённые пользователи. Первая строка — администратор бота, ему пересылаются запросы и технические сообщения.
- **`ignored_users.txt`** — игнорируемые пользователи, им бот не отвечает вообще.

Пользователь, которого нет в списке разрешённых, получает предупреждение, а его текстовые и голосовые сообщения пересылаются администратору. Можно отправить не более 3 таких сообщений (счётчик в памяти), после чего пользователь автоматически добавляется в `ignored_users.txt`, о чём администратор уведомляется.

## Логирование

Уровень `DEBUG` показывает в логе:
- RAW-запрос к Whisper API (URL, модель, файл, промпт, температура, язык)
- RAW-ответ от API (статус, тело ответа)

## Параметры модели

Внутренние module-level переменные в `whisper_client.py` для тонкой настройки:

- `TEMPERATURE` — умолчание для температуры (0.0)
- `LANGUAGE` — умолчание для языка (None — автораспознавание)
- `RESPONSE_FORMAT` — формат ответа (`"json"`)
- `TIMESTAMP_GRANULARITIES` — таймстемпы слов/сегментов (None)

## Будущие улучшения

- **Idle-timeout для HTTP-клиента** — автоматически закрывать соединение с Whisper API после длительного простоя (~20ч), чтобы не висеть открытым между сессиями.
