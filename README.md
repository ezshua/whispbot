# WhispBot

Telegram-бот для транскрибации аудио и видео в текст через OpenAI-совместимый Whisper API.

Поддерживает модели `whisper-large-v3`, `whisper-large-v3-turbo`, `whisper-1` и любые другие через смену параметра.

## Требования

- Python ≥ 3.10
- [uv](https://docs.astral.sh/uv/) (менеджер пакетов)
- [ffmpeg](https://ffmpeg.org/) (конвертация аудио)

## Установка

```bash
git clone <repo>
cd whispbot
uv sync
```

## Настройка

Скопировать `.env.example` в `.env` и заполнить:

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | — |
| `WHISPER_API_BASE_URL` | Адрес Whisper API | — |
| `WHISPER_API_KEY` | API-ключ | — |
| `WHISPER_MODEL` | Модель при старте | — |
| `WHISPER_PROMPT` | Опциональный системный промпт | `""` |
| `FILES_MAX_FILE_SIZE_MB` | Максимальный размер файла (MB) | `25` |
| `FILES_TEMP_DIR_PATH` | Путь к временной папке | `"temp"` |
| `FILES_ALLOWED_AUDIO_EXTENSIONS` | Разрешённые аудиоформаты | `".mp3,.wav,.m4a,.flac,.aac,.opus,.ogg,.wma,.aiff"` |
| `FILES_ALLOWED_VIDEO_EXTENSIONS` | Разрешённые видеоформаты | `".mp4,.webm,.mkv,.mov,.avi,.flv,.m4v,.3gp,.ts"` |
| `FILES_KEEP_TEMP_FILES` | Не удалять файлы после обработки | `"false"` |
| `ACCESS_ALLOWED_USERS_FILE` | Файл списка разрешённых пользователей (первая строка — администратор) | `"allowed_users.txt"` |
| `ACCESS_IGNORED_USERS_FILE` | Файл списка игнорируемых пользователей | `"ignored_users.txt"` |
| `LOG_LEVEL` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`) | `"INFO"` |

## Запуск

```bash
.venv\Scripts\activate
python -m src.bot
```

Либо двойным кликом на `start.bat`.

Остановка: `Ctrl+C`.

## Команды

| Команда | Описание |
|---|---|
| `/start` | Обычный режим (двухфазный: «Слушаю...» → текст) и показ ваших текущих настроек |
| `/startmin` | Минимальный режим (одно сообщение с результатом, без «Слушаю...») |
| `/help` | Справка по всем командам и форматам |
| `/lang <код>` | Установить язык распознавания (ISO-639-1: `ru`, `en`…) или `auto` |
| `/temp <0.0–1.0>` | Установить температуру модели (разделитель `,` или `.`) |
| `/model large` | Переключиться на `whisper-large-v3` |
| `/model turbo` | Переключиться на `whisper-large-v3-turbo` |
| `/adduser <id> [имя]` | Добавить пользователя в список разрешённых и удалить из игнорируемых (только для администратора) |
| `/deluser <id>` | Переместить пользователя из разрешённых в игнорируемые (только для администратора) |
| `/listuser` | Показать двумя сообщениями списки разрешённых и игнорируемых (только для администратора) |

## Использование

Отправьте боту аудио (MP3, WAV, M4A), видео (MP4, WEBM), голосовое сообщение или кружок — бот вернёт текстовую расшифровку.

По умолчанию включён **двухфазный режим**: сначала «Слушаю...», затем замена на текст. Команда `/startmin` переключает в **минимальный режим** — бот сразу отвечает одним сообщением с результатом (полезно для цепочек ботов).

## Индивидуальные настройки

Настройки транскрибации (**язык**, **температура**, **модель**, **режим ответа**) индивидуальны для каждого пользователя и хранятся в памяти бота (`context.user_data`), поэтому сбрасываются при его перезапуске.

- Команда `/start` показывает текущее состояние ваших настроек.
- Команды `/lang`, `/temp`, `/model`, `/startmin` меняют настройки только для вызвавшего их пользователя и не влияют на остальных.

Поддерживаемые типы входящих сообщений:
- **Аудиофайлы** — конвертируются в WAV (16kHz, mono) через ffmpeg
- **Видеофайлы** — извлекается аудиодорожка, затем транскрибация
- **Голосовые сообщения** (Voice) — конвертация OGG → WAV
- **Видеокружки** (Video Note) — извлечение аудио из MP4
- **Документы** — если расширение в списке разрешённых

## Доступ пользователей

Бот читает два списка при старте (формат строки: `<user_id>; <имя или комментарий>`, строки с `#` и пустые пропускаются):

- **`allowed_users.txt`** — разрешённые пользователи. Первая строка — администратор бота, ему пересылаются запросы и технические сообщения.
- **`ignored_users.txt`** — игнорируемые пользователи, им бот не отвечает вообще.

Пользователь, которого нет в списке разрешённых, получает предупреждение, а его текстовые и голосовые сообщения пересылаются администратору. Можно отправить не более 3 таких сообщений (счётчик в памяти), после чего пользователь автоматически добавляется в `ignored_users.txt`, о чём администратор уведомляется.

## Логирование

Уровень `DEBUG` показывает в логе:
- RAW-запрос к Whisper API (URL, модель, файл, промпт, температура, язык)
- RAW-ответ от API (статус, тело ответа)

## Параметры модели

Внутренние module-level переменные в `whisper_client.py` для тонкой настройки:

- `TEMPERATURE` — умолчание для температуры (0.0)
- `LANGUAGE` — умолчание для языка (None — автораспознавание)
- `RESPONSE_FORMAT` — формат ответа (`"json"`)
- `TIMESTAMP_GRANULARITIES` — таймстемпы слов/сегментов (None)

## Будущие улучшения

- **Idle-timeout для HTTP-клиента** — автоматически закрывать соединение с Whisper API после длительного простоя (~20ч), чтобы не висеть открытым между сессиями.
